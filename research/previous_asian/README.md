# Previous Asian research

Preserved from the non-Git August 4, 2026 Asian prototype before the directory
was archived. These files contain a scalar arithmetic-Asian reference,
Brownian-bridge construction, experimental AVX-512 kernels, generated W/lane
assets, and tests.

They are not part of the current build. The `rank1`, `coefficient-pair`, and
`final-z` direction-number constructions remain experimental and must not be
treated as validated replacements for OpenEvolve.
