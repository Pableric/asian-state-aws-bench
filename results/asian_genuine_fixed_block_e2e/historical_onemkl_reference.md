# Frozen oneMKL reference policy

No exact qualified oneMKL JSON is present in the requested base tree, and no
historical path was supplied during local packaging. Local cells therefore use
`ONEMKL_REFERENCE_UNAVAILABLE`.

The optional importer records the supplied path, SHA-256, producing commit,
benchmark binary SHA-256, measurement date, and required contract. A row is
used only when the current run and frozen evidence match on CPU model, kernel,
physical CPU, thread settings, fenced-TSC/wall units, 4,096 paths, market
contract, N, K, estimator, cache mode, complete two-sided full-risk output set,
the explicit `asian_qualified_nested_strikes_v1` strike contract, and one
common Gaussian matrix plus one matched forward evolution.

Imported ratios are labelled `cross_run_reference=true`,
`paired_measurement=false`, and `confidence_bound_claim=false`. The benchmark
does not build, link, invoke, or test oneMKL and does not alter any historical
evidence.
